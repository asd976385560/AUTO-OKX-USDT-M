## 本地保留、公开排除 / Local-only exclusions

本地工作区还可能保留宿主升级、质量优化、数据增强等内部维护资料；
这些文件、真实运行记录和宿主标识均不属于公开文档面。

`archive/` 中均为已完成、已取代或一次性的切换、迁移、测试和审查材料。它们只供本地追溯，不进入公开发布，也不能覆盖当前运行口径。

The same local-only files and everything under `archive/` remain excluded from the public release. They are historical or host-specific references and do not override the current V2.0 contract.
