# 文档状态索引

公开代码事实以根目录 `skill.md`、`README.md`、`config.example.md` 和真实源码为准。部署后的私有运行状态应在本机独立核验。

本地工作区还可能保留下列内部维护资料，但公开发布默认排除：

- `openclaw_host_upgrade_runbook.md`：主机升级与恢复操作手册。
- `quality-optimization-plan-v1.1.md`：仍在引用的质量优化方案。
- `data_enrichment_execution_plan_20260720.md`：数据增强执行记录与剩余事项。

`archive/` 中均为已完成、已取代或一次性的切换、迁移、测试和审查材料。它们只供本地追溯，不进入公开发布，也不能覆盖当前运行口径。
